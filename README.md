# Web Userscripts Collection

Welcome to my personal collection of Userscripts designed to enhance web browsing experiences by tweaking user interfaces, automating tedious interactions, and removing annoyances. 

These scripts run via userscript managers like [Violentmonkey](https://violentmonkey.github.io/) or [Tampermonkey](https://www.tampermonkey.net/).

## Installation

1. Install a userscript manager extension for your browser (e.g., Violentmonkey or Tampermonkey).
2. Click on the raw `.user.js` file from this repository you want to install.
3. Your userscript manager will automatically prompt you to install it.
